## 2. 命名方案（最关键，办证前必读）

抖音《小游戏审核规范》命名规则 13：**「小游戏名称需与软著、版号保持完全一致，如软著与版号名称包含特殊符号，可在名称中省略。」**

同时中国版权保护中心（CPCC）要求软件全称一般以「软件 / 系统 / 平台 / APP」等结尾，直接登记「引力方块」大概率被要求补正。

**兼顾两边的标准做法：**

| 字段 | 填写 |
|---|---|
| 软件全称 | **引力方块游戏软件** |
| 软件简称 | **引力方块**（登记后证书会体现简称，用它对齐抖音小游戏名称） |
| 版本号 | **V1.0** |

⚠️ 稳妥起见：**提交 CPCC 前**先在抖音开放平台客服/资质页确认「软著全称=引力方块游戏软件（简称：引力方块）」能否通过名称一致性校验（实践中绝大多数同类小游戏按此通过）。若走路线②，代办方会替你把关。名称一旦登记，改名 = 重新登记，成本高。

## 3. CPCC 在线申请步骤（路线①）

1. 打开中国版权保护中心官网 <https://www.ccopyright.com.cn/> → 「在线办事」→ **计算机软件著作权登记**（全程网办）
2. **注册个人账号 + 实名认证**（身份证 + 人脸/银行卡核验）
3. 新建登记申请，按下方速查表逐项填写
4. 上传申请材料（PDF）：
   - **源程序**：`软著材料/源程序代码.pdf`（全部 51 页；规定为前 30 + 后 30 页，不足 60 页须全部提交 ✅）
   - **文档**：`软著材料/操作说明书.pdf`（12 页，含界面图）
   - **身份证明**：身份证人像面 + 国徽面（拍照/扫描清晰件）
5. 确认提交（免费，无官费）
6. 留意短信/站内通知：材料不齐会发**补正通知**，登录系统按提示补正后重新提交
7. 受理 → 审查 → 登记发证：**电子证书在系统内下载**（可自行打印），周期约 30~40 个工作日

## 4. 拿到证书后：抖音后台提交

1. 抖音开放平台控制台 → 你的小游戏 → 你截图的那个**类目资质（软著）页面**
2. 选择资质类型「计算机软件著作权登记证书」，按证书原件逐项填写：
   - 软件名称（照证书抄，含全称/简称）
   - **登记号**（形如 `2026SR×××××××`）
   - 版本号（V1.0）、著作权人、登记批准日期
   - 上传证书扫描件/清晰照片（电子证书可转成图片上传）
3. 提交 → 平台审核（即你截图页面说的「证书审核通过后游戏方可发布上线」，一般数个工作日）
4. 审核通过 + **ICP 备案通过** + 版本审核通过 → 版本管理里才能点「发布」

### 「修改证书会导致已备案信息失效」是什么意思

证书信息过审后会与小游戏的**备案信息绑定**。此后若在这个页面修改/更换证书（改名、换登记号、换著作权人），已通过的备案随之失效，需要**重新走 1~3 周的管局备案**，期间无法发布更新。
👉 所以提交前逐项核对：**软著名称 ↔ 小游戏名称一致、著作权人 ↔ 开发者实名一致、版本号 V1.0**，一次填对，之后不要再动。
